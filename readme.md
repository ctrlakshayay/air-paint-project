# 🎨 Air Paint Project

A computer vision project using OpenCV that allows users to draw in air using colored object tracking.

## 🚀 Features

* Real-time object tracking
* Air drawing using webcam
* Motion detection

## 🛠️ Tech Stack

* Python
* OpenCV
* NumPy

## ▶️ How to Run

```bash
python3 paint.py
```
